# Brew & Bloom Cafe Landing Page

This is Project 1: a single-page landing page for a small cafe called "Brew & Bloom".

## Technologies Used
- HTML (for structure)
- CSS (for styling and simple layout)

## What I learned
- How to structure a webpage using basic HTML tags (headings, paragraphs, lists, links).
- How to connect a CSS file to an HTML document.
- How to use simple CSS properties like `color`, `background-color`, `padding`, and `margin`.
- How to use simple Flexbox (`display: flex`) to create a navigation bar.
- How to style a button using links (`<a>` tags) and CSS.
